# 漫剧工场 60 秒开源宣传片设计

## 目标

制作一支面向 AI 漫剧创作者的 60 秒高密度宣传片，用真实产品界面说明「漫剧工场」能够在一个网站内串联故事、角色与场景、关键帧与视频、制片导出的完整流程，并引导观众体验项目或在 GitHub 点亮 Star。

本片是产品认知宣传片，不承担完整教程功能。2–3 分钟的端到端工作流演示留作后续内容。

## 核心受众与信息

- 第一受众：正在使用多个 AI 工具制作漫剧、动态漫画或短剧的创作者。
- 核心痛点：剧本、提示词、角色参考、场景图、关键帧、视频片段散落在多个工具中，流程割裂且难以维护一致性。
- 核心承诺：一个网站串起从故事到可导出视频资产的完整生产流程。
- 差异化卖点：关键帧驱动、角色与场景资产复用、镜头级工作台、统一制片导出。
- 次要信息：项目开源，支持 Web、Electron 和 Docker。

## 创意路线

采用「痛点反转型叙事 + 真实产品界面」组合：

1. 用多工具切换的痛点建立共鸣。
2. 以「现在，一个网站就够了」完成产品亮相。
3. 用真实界面快速走完 Phase 01–04，证明产品不是概念稿。
4. 用开源信息和 GitHub Star 作为行动召唤。

视频不得暗示当前项目已经自动生成完整成片。示例项目「凡人」有 16 个镜头，但当前仅 1 个镜头具备视频状态；宣传片应强调流程闭环和可用能力，不虚构完成度。

## 60 秒时间轴

### 0–4 秒：痛点钩子

- 画面：多个创作工具窗口或抽象卡片快速叠加切换，最后画面短暂停顿。
- 屏幕字幕：`做一部 AI 漫剧，要切多少个平台？`
- 声音：连续切换音效，结尾一次低频收束。

### 4–8 秒：产品亮相

- 画面：漫剧工场 Logo 进入，切到真实项目库界面。
- 旁白：`现在，一个网站就够了。`
- 屏幕字幕：`漫剧工场 MangaStudio`

### 8–17 秒：Phase 01 剧情创作

- 画面：示例项目「凡人」的故事梗概、角色表、7 个场景和 16 个镜头快速纵向移动；局部放大镜头卡片与提示词。
- 旁白：`输入一个故事，AI 帮你拆出角色、场景和可执行分镜。`
- 屏幕字幕：`故事 → 剧本 → 分镜`

### 17–27 秒：Phase 02 场景角色

- 画面：角色定妆、服装变体、场景概念图与横竖屏切换；优先展示已有生成图片。
- 旁白：`角色定妆、服装变体、场景概念图，统一沉淀成可复用资产。`
- 屏幕字幕：`保持角色与场景一致`

### 27–40 秒：Phase 03 AI 工作台

- 画面：镜头网格、SHOT 编号、首帧、视频状态、运镜标签和批量生成首帧按钮；突出 Dolly、Tilt、Circular、Zoom 等镜头信息。
- 旁白：`先定关键帧，再选择运镜，让每一个镜头按计划动起来。`
- 屏幕字幕：`关键帧驱动 · 镜头级控制`

### 40–49 秒：Phase 04 制片导出

- 画面：时间轴、Preview Video、Source Assets、Render Logs 和 EDL/XML 导出入口。
- 旁白：`集中预览、管理素材，并导出视频与后期工程数据。`
- 屏幕字幕：`预览 · 管理 · 导出`

### 49–55 秒：价值总结

- 画面：Phase 01–04 四块真实界面依次拼合，形成完整工作流。
- 旁白：`从一个故事，到一部会动的漫剧。`
- 屏幕字幕：`一站式 AI 漫剧创作工作台`

### 55–60 秒：行动召唤

- 画面：Logo、GitHub 仓库信息与 Web / Electron / Docker 标签。
- 旁白：`漫剧工场，现已开源。欢迎体验，点亮 Star。`
- 屏幕字幕：`开源 · 立即体验 · GitHub Star`

## 视觉与声音

- 画幅：首版使用 16:9、1920×1080，兼容 GitHub、B 站和 YouTube；后续可从安全区裁切 9:16 版本。
- 视觉：深色工业界面为主，青蓝到紫色渐变作为品牌强调色。
- 动效：界面推拉、局部放大、遮罩滑动、快速匹配剪辑；避免花哨转场遮挡产品信息。
- 字幕：每屏只保留一个短句，字号适合移动端观看，关键词使用青蓝或紫色高亮。
- 旁白：中文，沉稳、清晰、略快；句子短，避免技术术语堆叠。
- 音乐：具有科技感与推进感的无歌词背景音乐，在 4、17、27、40、55 秒设置节拍节点。
- 音效：工具切换、轻微推入、卡片出现和结尾 Logo 收束；音效不得压过旁白。

## 素材策略

- 主要素材：本地真实运行界面和仓库 `images/` 下的高分辨率截图。
- 示例内容：优先使用「凡人」项目中已有的 3 个角色、7 个场景和 16 个镜头数据。
- Logo：使用 `public/logo.svg`。
- 禁用素材：`server/shot1_db.mp4` 当前媒体结构无效，不纳入制作。
- 若缺少可播放成片镜头，使用关键帧的缓慢推拉或视差动效，不伪造完整视频生成结果。
- 所有第三方音乐、字体和补充素材必须可用于开源项目宣传，并记录许可来源。

## 自动制作流程

1. 在固定 16:9 视口下录制或截取 Phase 01–04 的真实页面状态。
2. 选择能对应每句旁白的界面片段，按时间轴裁切。
3. 合成品牌开场、字幕、局部放大和界面拼接动效。
4. 生成或录制中文旁白，自动对齐字幕。
5. 混合背景音乐与界面音效，保证旁白清晰。
6. 输出 1080p H.264 MP4，并生成封面候选图。

## 异常与降级

- API 生成不可用：只录制已有项目数据，不触发在线生成。
- 页面加载较慢：使用仓库现有高分辨率截图替代对应录屏段落。
- 视频素材不可播放：使用关键帧推拉、蒙版和轻视差表达动态。
- 字幕拥挤：优先删减说明，不缩小到移动端不可读。
- 60 秒超时：先缩短界面停留，再精简旁白，不删除 Phase 01–04 中的任何阶段。

## 验收标准

- 总时长控制在 58–62 秒。
- 前 5 秒内明确提出多工具切换痛点，并展示产品名称。
- 四个生产阶段均被真实展示，且观众能理解其先后关系。
- 全片不声称已生成 16/16 完整视频，也不展示不可播放的伪成片。
- 移动端观看时，关键字幕无需暂停即可读清。
- 旁白、字幕和画面所述功能都能在当前项目中找到对应入口或数据。
- 片尾包含项目开源信息和明确的体验/Star 行动召唤。
- 输出文件可在常见浏览器、B 站和 YouTube 上传链路中正常播放。
