## 二、本次发现并修复的部署问题（3 个）

集成测试暴露了三个镜像/编排缺陷，均已修复：

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 前端镜像构建失败（postinstall 退出 1） | Dockerfile 在 `COPY . .` 之前就执行 `npm install`，postinstall 找不到 `scripts/copy-ffmpeg-core.js` | `COPY scripts ./scripts` 提前于依赖安装（`Dockerfile`） |
| 2 | 构建上下文污染（无 .dockerignore） | 本地 macOS node_modules、700MB 备份会被 COPY 进 linux 镜像 | 新增根目录与 `server/` 两份 `.dockerignore` |
| 3 | nginx 502（启动时序） | frontend 先于 api 启动，nginx 启动时解析 upstream 得到 Docker Desktop 临时代理 IP 并永久缓存 | api 增加 healthcheck，frontend `depends_on: api: service_healthy`；postgres 补 healthcheck |
